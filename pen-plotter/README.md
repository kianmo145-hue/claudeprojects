# پلاتر قلم با موتور DC گیربکس‌دار

ساخت پن‌پلاتر (مثل ریل Drawscape) با کمترین امکانات:
آردوینو Uno R3 + درایور L298N + موتور DC گیربکس‌دار + انکودر دست‌ساز + یک سروو برای قلم.

## فاز ۱ — تست تک‌موتور (`phase1_motor_test/`)

هدف: ثابت کنیم یک موتور DC با انکودر دست‌ساز می‌تواند دقیق به موقعیت دلخواه برود و برگردد.

### سیم‌کشی

| قطعه | پایه قطعه | آردوینو |
|---|---|---|
| L298N | ENA (جامپرش را بردار) | D5 |
| L298N | IN1 | D7 |
| L298N | IN2 | D8 |
| L298N | OUT1 / OUT2 | دو سر موتور |
| L298N | +12V / GND | آداپتور ۹ تا ۱۲ ولت |
| L298N | GND | GND آردوینو (**زمین مشترک حتماً**) |
| سنسور انکودر (TCRT5000) | VCC / GND | 5V / GND آردوینو |
| سنسور انکودر | D0 (خروجی دیجیتال) | D2 |
| سروو (فاز بعد) | سیم سیگنال | D9 |

### نکات ضد نویز
- خازن 100nF سرامیکی مستقیم دو سر موتور.
- سیم انکودر را از سیم‌های موتور دور نگه دار (در صورت امکان به‌هم‌تابیده با GND).
- پتانسیومتر روی ماژول TCRT5000 را آن‌قدر بچرخان که LED روی شیار/خط سیاه و سفید تمیز خاموش-روشن شود.

### هشدار ولتاژ موتور
موتورهای TT زرد ۳ تا ۶ ولتی‌اند. L298N حدود ۲ ولت می‌اندازد، ولی با آداپتور ۹-۱۲ ولت
باز هم ولتاژ زیاد است. در کد `maxPwm` سقف ولتاژ مؤثر است (پیش‌فرض 140). بالاتر نبر مگر
موتورت تحملش را داشته باشد.

### راه‌اندازی
1. کد `phase1_motor_test.ino` را روی Uno بریز (Arduino IDE).
2. Serial Monitor را با **115200** باز کن، خط پایان newline.
3. دستورها:
   - `Z` صفر کردن موقعیت
   - `M 400` برو به موقعیت ۴۰۰ پالس
   - `R -120` حرکت نسبی
   - `P` گزارش موقعیت
   - `V 120` سقف PWM (ولتاژ)
   - `W 90` سرعت خزش نزدیک هدف
   - `T 2` تلرانس قبول خطا
   - `C` کالیبراسیون: ۱۰۰۰ پالس می‌رود؛ جابه‌جایی را میلی‌متری اندازه بگیر → `counts_per_mm = 1000 ÷ mm`

### منطق حرکت (همان استراتژی «برو، بعد اصلاح کن»)
1. تا نزدیکی هدف تند می‌رود، در «ناحیه خزش» آرام می‌شود.
2. ترمز می‌کند، ۲۰۰ms صبر می‌کند تا مکانیک بایستد.
3. اگر خطا ماند، با پالس‌های کوتاه (nudge) اصلاح می‌کند.
4. رسیدن به هدف همیشه از یک جهت انجام می‌شود تا لقی گیربکس حذف شود
   (اگر هدف عقب‌تر باشد، اول کمی بیشتر عقب می‌رود و از پایین برمی‌گردد).

### پیشنهاد مکانیک: پیچ متری M8 به‌جای تسمه
انکودر بعد از گیربکس تفکیک‌پذیری کمی دارد. با میلهٔ رزوه‌دار M8 (هر دور = ۱.۲۵mm حرکت)
همان دیسک ۲۰ شیاره دقت ~۰.۰۶mm بر پالس می‌دهد. حرکت کند می‌شود (۲-۳ mm/s) ولی برای
پلاتر کافی است و نیروی نگهدارنده هم دارد.

## فازهای بعد
- فاز ۲: محور دوم + سروو قلم + حالت «اگر وسط خط خطا زیاد شد: قلم بالا، اصلاح، قلم پایین، ادامه».
- فاز ۳: گرفتن مسیرهای `G1 X.. Y..` از سریال و رسم فایل واقعی (تولید مسیر از SVG با اسکریپت پایتون).
