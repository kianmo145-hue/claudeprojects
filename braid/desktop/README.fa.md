# Braid برای ویندوز

همهٔ اتصال‌ها را با هم استفاده کنید: وای‌فای، LAN، تترینگ گوشی، و دیتای موبایل گوشی از طریق همان وای‌فای (بوستر). روی آیکن Braid کنار ساعت بزنید:

- **بالای منو**: وضعیت و سرعت کل. رنگ آیکن: خاکستری متوقف، کهربایی یک اتصال، سبز در حال ترکیب؛ نشانک گوشی یعنی بوستر در کار است.
- **لینک‌ها**: هر اتصال با سرعت، سهم (▰▰▱▱▱) و تعداد اتصال‌ها؛ برای محدود کردن سرعت روی آن بزنید.
- **گوشی‌ها (بوستر)**: گوشی‌های روی وای‌فای شما. «جفت شدن با این گوشی…» و مقایسهٔ کد شش رقمی.
- **تنظیمات**: IPv6، توقف خودکار با یک اتصال، اجرا هنگام ورود، زبان (فارسی / English).
