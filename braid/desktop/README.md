# Braid for Windows

Use all your connections at once: Wi‑Fi, Ethernet, a phone tether, and a phone's mobile data over the
same Wi‑Fi (booster). Click the Braid icon next to the clock:

- **Header**: state and total speed. Icon colour: grey paused, amber one connection, green merging,
  phone badge while a booster phone is used.
- **Links**: each connection with its speed, its share (▰▰▱▱▱) and open flows; click one for a speed cap.
- **Phones (booster)**: phones on your Wi‑Fi. *Pair with this phone…*, then compare the six-digit code.
- **Settings**: IPv6 behaviour, pause with one connection, start at sign-in, language (فارسی / English).

Command line (`braid.exe`): `tray`, `run`, `on`, `off`, `quit`, `status`, `list`, `limit`,
`autostart on|off`, `cleanup`, `version`.
