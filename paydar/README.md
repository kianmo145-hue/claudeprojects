# پایدار (Paydar)

**کلاینت VPN برای ویندوز و اندروید با تمرکز روی اتصال پایدار.** کانفیگ‌ها و اشتراک‌های v2ray
(VLESS، VMess، Trojan، Shadowsocks، Hysteria2، TUIC) را می‌گیرد و **خودش** بین آن‌ها سوییچ می‌کند
تا اتصال قطع نشود. هستهٔ آن [sing-box](https://github.com/SagerNet/sing-box) است.

[English](README.en.md)

## فرق با کلاینت‌های دیگر

کلاینت‌هایی مثل v2rayNG یا Hiddify معمولاً یا یک سرور را نگه می‌دارند تا وقتی خودتان عوضش کنید، یا با
`urltest` هر چند دقیقه یک بار پینگ می‌گیرند. «پایدار» یک **نگهبان (guard)** دارد که مدام کار می‌کند:

| | چه می‌کند |
|---|---|
| **پایش سرور فعال** | هر ۵ ثانیه یک درخواست واقعی (HTTP 204) از داخل همان سرور. دو خطای پشت‌سرهم (دومی با یک ثانیه فاصله) یعنی قطع. |
| **سوییچ فوری** | اول سرورهای «آماده» (که همین الان تست شده‌اند) امتحان می‌شوند؛ اگر نشد، **همهٔ سرورها همزمان مسابقه می‌دهند** و اولین سرور سالم برنده است. معمولاً کمتر از ۱۰ ثانیه. |
| **سرورهای آماده** | ۳ سرور برتر هر ۳۰ ثانیه تست می‌شوند تا جایگزین همیشه معلوم باشد. |
| **امتیاز واقعی** | میانگین پینگ، نوسان (jitter) و درصد موفقیت در ۸ تست آخر؛ سرور خراب برای مدتی (۳۰ ثانیه تا ۱۰ دقیقه، به‌تدریج بیشتر) کنار گذاشته می‌شود. |
| **تشخیص قطعی اینترنت خودتان** | اگر هیچ سروری جواب ندهد، اتصال مستقیم هم چک می‌شود. اگر اینترنت خودتان قطع باشد، سرورها «خراب» حساب نمی‌شوند و الکی سوییچ نمی‌شود. |
| **بدون رفت‌وبرگشت بی‌دلیل** | رفتن به سرور سریع‌تر فقط وقتی که حداقل ۲ برابر بهتر و پایدار باشد، و حداکثر هر ۱۰ دقیقه یک بار (هر سوییچ اتصال‌های باز را قطع می‌کند). |
| **احترام به انتخاب شما** | اگر سروری را خودتان انتخاب کنید، فقط وقتی قطع شود از آن جدا می‌شود و وقتی دوباره سالم شد، به آن برمی‌گردد. |
| **عوض شدن شبکه** | در اندروید با عوض شدن وای‌فای/دیتا، همان لحظه دوباره چک می‌کند (و اگر DNS شبکه عوض شده، هسته را با DNS جدید راه می‌اندازد). |
| **اتصال‌های مرده نمی‌مانند** | بعد از سوییچ، اتصال‌های قبلی بسته می‌شوند تا برنامه‌ها فوراً از سرور جدید وصل شوند (به‌جای اینکه روی تونل مرده گیر کنند). |
| **شروع سریع** | آخرین سروری که کار کرده یادش می‌ماند و اتصال بعدی با همان شروع می‌شود. |
| **اشتراک‌ها** | به‌روزرسانی خودکار (طبق هدر `profile-update-interval` یا هر ۱۲ ساعت)، نمایش حجم مصرفی و انقضا. اگر لینک اشتراک فیلتر باشد، از داخل خود VPN دانلود می‌شود. اگر دانلود نشد، لیست قبلی حفظ می‌شود. |

## امکانات

- **ویندوز**: حالت TUN (کل سیستم، پیشنهادی) یا پراکسی سیستم. آیکن کنار ساعت (خاکستری: قطع، زرد: در حال اتصال/بدون اینترنت، سبز: متصل). پراکسی محلی SOCKS/HTTP روی `127.0.0.1:12334`.
- **اندروید ۸ به بالا**: VPN کامل، کاشی Quick Settings، اعلان با نام سرور فعال و دکمهٔ قطع، «اشتراک‌گذاری» لینک از برنامه‌های دیگر به پایدار.
- سایت‌های `.ir` مستقیم (قابل خاموش کردن)، DNS از داخل تونل (DoH)، شبکهٔ محلی همیشه مستقیم.
- تست همهٔ سرورها حتی وقتی وصل نیستید، حذف سرورهای خراب با یک دکمه.
- رابط فارسی/انگلیسی، روشن/تیره (طبق سیستم).

## دانلود

بعد از هر تغییر، GitHub Actions همه چیز را می‌سازد:

- ریلیز `paydar-latest`: `paydar-android.apk` (اندروید)، `paydar-setup.exe` (نصب ویندوز)، `paydar-*-portable.zip`
- همین فایل‌ها روی شاخهٔ `paydar-builds` (اگر دانلود از ریلیز فیلتر بود)

## ساختار

```
paydar/
  internal/link     خواندن لینک‌ها و اشتراک‌ها (vless/vmess/trojan/ss/hy2/tuic، base64، JSON سینگ‌باکس)
  internal/build    ساخت کانفیگ sing-box
  internal/guard    نگهبان: پایش، امتیازدهی، سوییچ خودکار (قلب برنامه)
  internal/engine   اجرای sing-box و اتصال نگهبان به آن
  internal/app      سرورها، اشتراک‌ها، تنظیمات، اتصال
  internal/api      API محلی (127.0.0.1 + توکن تصادفی) و سرو کردن رابط کاربری
  web/              رابط کاربری مشترک (HTML/JS) برای ویندوز و اندروید
  cmd/paydar        برنامهٔ ویندوز (آیکن کنار ساعت، پنجره با Edge)
  mobile/           هستهٔ اندروید (gomobile) + tun2socks
  android/          برنامهٔ اندروید (Kotlin، WebView، VpnService)
```

## ساخت

```bash
# تست‌ها (شامل یک تست واقعی سوییچ بین دو سرور shadowsocks محلی)
go test -tags with_gvisor,with_quic,with_utls,badlinkname,tfogo_checklinkname0 -ldflags=-checklinkname=0 ./...
```

```bash
# اجرای بدون آیکن (برای توسعه): آدرس رابط را چاپ می‌کند
go run -tags with_gvisor,with_quic,with_utls,badlinkname,tfogo_checklinkname0 -ldflags=-checklinkname=0 ./cmd/paydar -headless
```

ویندوز: `scripts\build-windows.ps1 -Version 0.1.0` (Go و Inno Setup 6).
اندروید: `android/scripts/build-go.sh` و بعد `./gradlew assembleRelease` (Android SDK و NDK).

## محدودیت‌های این نسخه

- پروتکل‌های مخصوص Xray که sing-box ندارد (XHTTP/SplitHTTP، mKCP، هدر HTTP روی TCP) پشتیبانی نمی‌شوند و هنگام افزودن، دلیلش نشان داده می‌شود.
- WireGuard هنوز اضافه نشده.
- «ایرانی مستقیم» فقط دامنه‌های `.ir` را شامل می‌شود (نه IPهای ایران).

## مجوز

GPL-3.0-or-later (چون sing-box با GPL منتشر شده). فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) با مجوز SIL OFL.
پایدار پروژه‌ای مستقل است و وابسته به sing-box یا سازندگانش نیست.
